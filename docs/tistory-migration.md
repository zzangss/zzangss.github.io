# 티스토리 이전 계획

기준일: 2026-07-31

기존 블로그: <https://hcw900517.tistory.com/>

## 결정

- 티스토리는 새 블로그가 안정적으로 운영될 때까지 유지한다.
- 새 글은 GitHub 블로그에서 작성한다.
- 기존 65개 글은 일괄 복사하지 않고 가치가 높은 글부터 선별해 다듬는다.
- 이전한 글에도 원래 작성일과 기존 글 주소를 메타데이터로 남긴다.
- 새 글이 검색 결과에 자리 잡기 전까지 티스토리 원문을 삭제하지 않는다.

## 이전 순서

1. 최근 글과 프로젝트·개념 정리 글의 목록을 만든다.
2. 글별로 본문, 코드, 표, 이미지의 소유권과 정상 표시 여부를 확인한다.
3. HTML 표현을 Markdown으로 정리한다.
4. 이미지 파일을 `public/images/<slug>/`로 옮기고 외부 핫링크를 제거한다.
5. 새 블로그에서 모바일·데스크톱 표시와 링크를 확인한다.
6. 티스토리 원문 상단에 새 글 주소 안내를 추가한다.
7. 검색 유입이 안정된 뒤 원문 유지 또는 비공개 여부를 개별 결정한다.

## 우선 이전 후보

- Nginx 핵심 개념 정리
- 애자일 철학과 방법론 정리
- 하이퍼바이저란?
- vCPU 동작 원리
- AWS 네트워크 핵심 구성 요소 정리
- Kata Containers와 gVisor
- Docker 가상화 원리와 리눅스 커널 구조

알고리즘 풀이 글은 문제별 이전보다 주제별 회고 글로 다시 구성하는 것을 우선한다.

## 주의사항

- 티스토리의 과거 XML 데이터 백업 기능은 2016년에 종료되었다.
- 공개 페이지를 기반으로 이전 도구를 만들 경우, 본문뿐 아니라 첨부 이미지와
  코드 블록을 반드시 별도로 검증한다.
- 기존 URL을 그대로 유지할 수 없으므로 검색 엔진에 중복 문서가 장기간 노출되지
  않도록 이전 안내와 canonical 정책을 함께 적용한다.
